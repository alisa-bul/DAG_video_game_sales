# DAG_video_game_sales
Задание получено в онлайн-школе KARPOV.COURSES: https://karpov.courses/ \
Пример использования DAG (Airflow) для решения аналитических задач.\
Это *учебный* проект, в котором необходимо **создать DAG**, состоящий из семи тасок, выгружающий данные о продажах видеоигр (https://kc-course-static.hb.ru-msk.vkcs.cloud/startda/Video%20Game%20Sales.csv) за некоторый год *(1994 + hash(f‘{login}') % 23)* и формирующий краткий отчет, отвечающий на следующие вопросы: 
- Какая игра была самой продаваемой в этом году во всем мире?
- Игры какого жанра были самыми продаваемыми в Европе? Перечислить все, если их несколько
- На какой платформе было больше всего игр, которые продались более чем миллионным тиражом в Северной Америке? Перечислить все, если их несколько
- У какого издателя самые высокие средние продажи в Японии? Перечислить все, если их несколько
- Сколько игр продались лучше в Европе, чем в Японии?
